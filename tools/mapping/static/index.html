Mulai scan

Scan sequential: stepper bergerak → hold → servo attach → sweep vertikal → servo detach → stepper lagi. Servo tidak pernah bergerak bersamaan dengan stepper. Gunakan jack 9V (bukan USB saja). Delay servo 0.1 s sudah terbukti aman untuk satu kolom 500–950 µs; jangan turunkan di bawah 0.05 s. Mulai dari Validation ±10° sebelum coarse full.

Model DL

—

—

Model 1D CNN binary empty/human disiapkan untuk berjalan di ESP32-S3 lewat TFLite Micro (firmware 0.8.0). Rule HLK tetap menjadi jalur buzzer/safety; panel ini menampilkan hasil DL live, latensi, dan metrik validasi blok waktu setelah board online.

Tren energi & jarak HLK

Garis cyan = energy (0–255), garis oranye = jarak (cm). Titik hijau = frame present, kuning = confirming/holding, abu = empty.

Panduan dataset

empty = tidak ada target. human = Anda bergerak/duduk/berdiri. non-human = benda dilempar/digoyang. Untuk aktivitas, rekam sesi terpisah walking/sitting/standing/lying.

Training: python tools/mapping/ml/train.py --data research/mapping/ml. Model yang dilatih nanti diintegrasikan ke ESP32-S3; dashboard ini tetap menampilkan presence/HLK.

Dashboard PC ini berjalan terpisah dari web diagnostik ESP32. Default bind 127.0.0.1; jangan port-forward ke internet.
